# Bastion

Персональное пространство для игры, анализа и изучения шахмат.

Этапы 1–2 завершены: требования, архитектура и интерактивный дизайн-прототип.
Stockfish, настоящая игра с компьютером и большая библиотека курсов входят в следующие этапы.

## Запуск

Нужны Node.js 24 и pnpm 11.25.0. На компьютере разработки можно дважды нажать `Start Bastion.cmd`: он использует установленный pnpm или runtime Codex.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте http://127.0.0.1:5173. Сервер слушает только localhost. Остановить — Ctrl+C в окне запуска. Если порт занят, проверьте уже открытый экземпляр приложения. HTML из dist не предназначен для открытия через file://.

```sh
pnpm test
pnpm build
pnpm preview
```

Production preview открывается на http://127.0.0.1:4173. `pnpm check` проверяет типы, `pnpm format` форматирует исходники. CI выполняет install/test/build на GitHub Actions.

## Что можно попробовать

1. **Играть:** выбор цвета, времени и сложности; демонстрация 8 ходов испанской партии; движение по сценарию и переворот доски.
2. **Обучение:** 6 разделов будущей программы, поиск, фильтры, описание курса.
3. **Урок:** мат на последней горизонтали; ответ на доске или кнопками; подсказка, обратная связь, сохранение прохождения.
4. **Анализ:** 16 полуходов, переход к любой позиции, редакторские пояснения, закладка.
5. **Библиотека:** сохранённый образец, фильтр избранного и поиск.
6. **Оформление:** 3 темы интерфейса, 3 цвета доски, координаты, настройка переходов.

Все учебные позиции проверены независимой шахматной библиотекой. Фигуры — оригинальный классический 2D-набор Cburnett из Lichess. Шрифты и графика поставляются локально, API-ключи не требуются.

## Текущие ограничения

- Это прототип, а не завершённая шахматная программа. Свободная игра и импорт PGN/FEN — этап 3; движок — этап 5; действующие часы и компьютерный соперник — этап 6.
- 1 080 уроков — план библиотеки. Опубликован один демонстрационный урок.
- Хранилище настроек и закладок — localStorage браузера. Очистка данных браузера удалит эти записи; серверной синхронизации нет.
- Дизайн проверен в Chromium на Windows. Другие браузеры и Windows-установщик — будущие проверки.
- В поставке нет внешней языковой модели, онлайн-мультиплеера или рейтинговой системы.

# Bastion

Персональное пространство для игры, анализа и изучения шахмат.

Версия 0.4: игра со Stockfish, бесплатный разбор партий и полноценная система интерактивных уроков. Реализован локальный web-сценарий этапов 1–9; большие курсы и выпуск мобильных приложений остаются в плане.

## Запуск

Нужны Node.js 24 и pnpm 11.25.0. На компьютере разработки можно дважды нажать `Start Bastion.cmd`: он использует установленный pnpm или runtime Codex.

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Откройте http://127.0.0.1:5173. Сервер слушает только localhost. Остановить — Ctrl+C в окне запуска. Если порт занят, проверьте уже открытый экземпляр приложения. HTML из dist не предназначен для открытия через file://.

```sh
pnpm test
pnpm build
pnpm preview
```

Production preview открывается на http://127.0.0.1:4173. `pnpm check` проверяет типы, `pnpm format` форматирует исходники. CI выполняет install/test/build на GitHub Actions.

## Что можно попробовать

1. **Играть:** Stockfish 19 Lite / Full или два игрока на одной доске. Перетаскивание и нажатия, часы, шах, мат, рокировка, en passant и выбор фигуры при превращении.
2. **Настроить силу:** Elo 1320–3190, уровень Stockfish 0–20 или отдельная учебная сила 200–1300. Учебная шкала не является измеренным Elo. Силу можно изменить во время партии.
3. **Продолжить:** пауза, возврат хода, просмотр записи и восстановление после перезагрузки. Сохранение локальное, в этом браузере.
4. **Обучение:** 12 законченных миниуроков, 42 шага. Объяснения и примеры, задачи на доске, вопросы, выбор полей, подсказки, многоходовые решения, восстановление, заметки и повторение ошибок. 1000+ уроков остаются отдельным этапом наполнения.
5. **Оформление:** графитовая, светлая и вечерняя темы; три цвета доски; внешние координаты и уменьшение анимаций.
6. **Время:** пуля, блиц, рапид, классика и собственные часы со слайдерами и точным числовым вводом. Добавление за ход, игра без часов, реванш со сменой цвета и предложение ничьей.
7. **Библиотека:** автоматическое сохранение, поиск по названию и заметкам, избранное, фильтры результата, восстановление незаконченных партий и необязательная резервная копия в настройках.
8. **Разбор:** Stockfish Lite / Full, три варианта, график оценки, лучшие ходы, неточности, ошибки и упущенные шансы. Расчёт можно остановить; повторные позиции используют ограниченный кеш.

Звуки ходов включаются отдельно, громкость регулируется. При перетаскивании фигура движется отдельным слоем через requestAnimationFrame и transform; часы обновляются отдельно от доски.

Движок работает в Worker. Lite загружает около 1,8 МБ, Full — около 99 МБ. Файлы автоматически подготавливаются из точно закреплённого npm-пакета; внешние API не нужны. Классические фигуры Cburnett из Lichess поставляются без изменений.

Аккаунты, сетевые матчи, синхронизация, мобильные установочные пакеты и полный релизный аудит — следующие этапы. История ограничена 200 партиями и доступным местом браузера. Метки разбора — объяснимая эвристика Bastion, зависящая от глубины расчёта; они не воспроизводят закрытую классификацию Chess.com. Игровой экран не содержит импорта/экспорта файлов.

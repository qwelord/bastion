# Bastion

Персональное пространство для игры, анализа и изучения шахмат.

Текущий этап: требования, архитектура и интерактивный дизайн-прототип (этапы 1–2).
Stockfish, настоящая игра с компьютером и большая библиотека курсов входят в следующие этапы.

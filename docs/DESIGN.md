# Дизайн Bastion

## Направление

Современная шахматная комната: вес настоящих фигур, ореховая доска, спокойный свет. Доска — главный визуальный объект. Слева узкая постоянная навигация, справа содержательная рабочая панель. Никаких KPI-карточек, выдуманных рейтингов или декоративных графиков на стартовом экране.

## Основной экран

```
┌────────────┬───────────────────────────────────────────────┐
│ Bastion    │ Игра                         Оформление       │
│            ├────────────────────────┬──────────────────────┤
│ Играть     │ Соперник               │ Новая партия         │
│ Обучение   │                        │                      │
│ Анализ     │      Доска             │ Цвет / время / сила  │
│ Библиотека │                        │                      │
│            │ Вы                      │ Начать демо          │
│ Настройки  │ Управление             │ Пояснение статуса    │
└────────────┴────────────────────────┴──────────────────────┘
```

На экране обучения вместо шахматной комнаты — широкий разворот с реальным фрагментом урока и каталогом. На мобильном навигация сверху, доска перед панелью, ничего не обрезается.

## Критика первого направления

Отказались от чёрно-золотой luxury-подачи: она выглядела бы рекламной и мешала длительному анализу. Отказались от одинаковых карточек на каждом экране: курсы представлены списком, игра — рабочим пространством, урок — позицией с пояснением. Ореховый материал оставлен на самой доске, а не размазан по интерфейсу.

## Движение

Короткие переходы состояния и появления панелей; никаких бесконечных пульсаций. Reduced motion убирает анимацию. Темы: Клуб, Светлая, Вечер. Материал доски выбирается независимо: Орех, Сланец, Олива.

## Проверяемые сценарии

1. Выбрать цвет/время/силу → открыть демо партии → воспроизвести ход → вернуться к настройкам.
2. Обучение → фильтр уровня → открытый урок → неправильный ответ → подсказка → правильный ответ.
3. Анализ → следующий/предыдущий ход → переворот доски.
4. Оформление → тема/материал/reduced motion → перезагрузка сохраняет выбор.
5. Библиотека → избранное → открыть образец анализа.

# Дизайн Bastion

## Направление

Спокойный шахматный интерфейс с классическими фигурами Cburnett из Lichess и плоской доской. Доска — главный визуальный объект. Слева узкая постоянная навигация, справа содержательная рабочая панель. Не добавлять скриншоты в README и репозиторий. Никаких KPI-карточек, выдуманных рейтингов или декоративных графиков на стартовом экране.

## Токены

| Роль            | Значение                                  |
| --------------- | ----------------------------------------- |
| Фон             | `#252525` — графит                        |
| Поверхность     | `#2e2e2e` — поверхность                   |
| Текст           | `#f1eee8` — основной текст                |
| Вторичный текст | `#b7b0a5` — вторичный текст               |
| Акцент          | `#c8aa79` — песочный акцент               |
| Доска           | `#f0d9b5` / `#b58863` — классические поля |

Manrope для навигации, заголовков и рабочих экранов; Literata остаётся доступным для будущих учебных материалов. Оба локально, с кириллицей. Размеры 12/14/16/20/28/40 px, строки не шире 70 символов. Заголовки выравниваются влево.

## Основной экран

```
┌────────────┬───────────────────────────────────────────────┐
│ Bastion    │ Игра                         Оформление       │
│            ├────────────────────────┬──────────────────────┤
│ Играть     │ Соперник               │ Новая партия         │
│ Обучение   │                        │                      │
│ Анализ     │      Доска             │ Цвет / время / сила  │
│ Библиотека │                        │                      │
│            │ Вы                      │ Начать демо          │
│ Настройки  │ Управление             │ Пояснение статуса    │
└────────────┴────────────────────────┴──────────────────────┘
```

На экране обучения вместо шахматной комнаты — широкий разворот с реальным фрагментом урока и каталогом. На мобильном навигация сверху, доска перед панелью, ничего не обрезается.

## Критика первого направления

Отказались от чёрно-золотой luxury-подачи: она выглядела бы рекламной и мешала длительному анализу. Отказались от одинаковых карточек на каждом экране: курсы представлены списком, игра — рабочим пространством, урок — позицией с пояснением. Декоративная имитация дерева, объёмная рамка и тени убраны. В обучении показана настоящая позиция урока вместо композиции с увеличенными фигурами.

## Движение

Короткие переходы состояния и появления панелей; никаких бесконечных пульсаций. Reduced motion убирает анимацию. Темы: Клуб, Светлая, Вечер. Цвет доски выбирается независимо: Классическая, Серая, Зелёная.

## Проверяемые сценарии

1. Выбрать цвет/время/силу → открыть демо партии → воспроизвести ход → вернуться к настройкам.
2. Обучение → фильтр уровня → открытый урок → неправильный ответ → подсказка → правильный ответ.
3. Анализ → следующий/предыдущий ход → переворот доски.
4. Оформление → тема/цвет доски/reduced motion → перезагрузка сохраняет выбор.
5. Библиотека → избранное → открыть образец анализа.

## Доработка для живой игры

Основная палитра: графит #252525, поверхность #2e2e2e, навигация #202020, текст #f1eee8, вторичный текст #b7b0a5, песочный акцент #c8aa79. Светлая и более тёмная темы остаются альтернативами. Заголовки интерфейса используют Manrope, чтобы рабочий экран читался как приложение, а не рекламный разворот.

Буквы A–H и цифры 1–8 вынесены в отдельные рейки за пределами полей. При перевороте порядок меняется вместе с доской. Доска на широком экране ограничена также высотой окна, чтобы нижние координаты оставались видимыми.

Движение отвечает действиям: фигура следует указателю, допустимые поля подсвечиваются, обычный ход плавно перемещает фигуру, кнопки откликаются на нажатие, экран и диалог появляются мягко. Загрузка Stockfish показывает честное неопределённое ожидание с отменой, без фиктивных процентов. Все эффекты отключаются настройкой уменьшения движения.

Основной путь: выбрать Stockfish и числовую силу → начать партию → ходить → при необходимости поставить на паузу, изменить силу или продолжить после перезагрузки. Вспомогательные файловые функции убраны с этого пути по указанию владельца.

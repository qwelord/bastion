# Этапы 4–8: локальная версия 0.3

## Оформление и взаимодействие

Сохранён оригинальный классический набор Cburnett из Lichess. Темы интерфейса и доски независимы и не меняют партию. Светлая тема использует нейтральные поверхности и коричневый акцент, вечерняя — тёмные поверхности и песочный акцент. Перемещения, диалог превращения, переходы экранов и состояния кнопок учитывают reduced motion. Звуки синтезируются локально через Web Audio, включаются пользователем и имеют регулировку громкости.

Drag-and-drop не обновляет React на каждом pointermove: DragMotion объединяет события до одного кадра, перемещает отдельный слой через translate3d и обновляет подсветку только при смене клетки. Геометрия доски читается при начале жеста. Прокрутка, потеря захвата, смена позиции, переворот, пауза и размонтирование отменяют незавершённое перетаскивание. Часы имеют собственный цикл обновления; результаты и история модели кешируются до изменения позиции.

## Движок и игра

Stockfish 19.0.1 запускается локально в отдельном однонитевом Worker. Hash — 32 МБ. Игровой поиск ограничен временем; анализ использует до трёх вариантов и бюджет 0,3 / 0,7 / 2 секунды на позицию. Доступны Lite и Full. Отмена завершает Worker и инвалидирует старый запрос. Кеш содержит максимум 600 оценённых позиций в памяти вкладки; ключ учитывает движок, бюджет, исходную позицию и всю последовательность ходов.

Пресеты: пуля, блиц, рапид, классика. Собственные часы: 0–180 минут с шагом 15 секунд, добавление 0–60 секунд. Ноль минут означает игру без часов и без добавления. Категория определяется по оценке длительности с 40 добавлениями. Числовая сила, цвета, возврат хода, сдача, заявляемая ничья, сохранение и реванш работают вместе с часами.

Предложение ничьей Stockfish — политика Bastion: не раньше 20 полуходов и при абсолютной оценке не выше 0,35 пешки. Иначе компьютер отклоняет предложение. Оценка предложения выполняется на паузе, продолжение явно запускает игрок. Это не собственный механизм предложений Stockfish. Штатные режимы ослабления описаны в [документации Stockfish](https://official-stockfish.github.io/docs/stockfish-wiki/Stockfish-FAQ.html).

## Данные

Валидируемая библиотека localStorage v1: максимум 200 партий, общий лимит сериализованных данных 8 миллионов символов и фактическая квота браузера. У каждой партии постоянный ID, даты, название, заметка и избранное. Автосохранение обновляет существующую запись. Текущая партия дополнительно сохраняется при уходе со страницы и скрытии вкладки. Повреждённая библиотека блокирует перезапись; ошибки квоты видны пользователю. Другая вкладка с обновлённым сохранением останавливает устаревшую игровую сессию.

Библиотека содержит реальные партии, поиск по названию/заметке, фильтры, изменение названия, закладки, заметки, удаление с подтверждением и открытие незавершённой партии. Имя локального профиля, оформление и прогресс существующего урока переживают перезапуск. Это локальные данные без аккаунта и синхронизации.

В настройках находится необязательная JSON-копия только библиотеки: партии, заметки и избранное. Файл ограничен 8 МБ, проверяются формат, версия, ID и каждая партия. Перед добавлением есть подтверждение; совпадения сохраняют более новую запись. Оформление, имя и текущие часы копией не заменяются. На игровой экран файловые операции не возвращались.

## Методика разбора

Оценивается каждая позиция партии на полной выбранной силе, независимо от сложности соперника. Для хода сравниваются лучшая оценка до хода и оценка после фактического хода, приведённые к перспективе ходившей стороны. Отрицательная потеря из-за колебания поиска округляется до нуля. Форсированный мат представлен отдельно от обычной пешечной оценки; готовый мат и ничья распознаются правилами.

| Метка          | Условие                                       |
| -------------- | --------------------------------------------- |
| Вынужденный    | Единственный легальный ход                    |
| Лучший         | Ход совпадает с первой линией Stockfish       |
| Упущенный шанс | До хода ≥ +2,00, после < +0,50, потеря ≥ 1,80 |
| Грубая ошибка  | Потеря ≥ 2,50                                 |
| Ошибка         | Потеря ≥ 1,20                                 |
| Неточность     | Потеря ≥ 0,60                                 |
| Хороший        | Потеря ≥ 0,25                                 |
| Отличный       | Остальные ходы                                |

Условия проверяются сверху вниз. Это воспроизводимая эвристика, а не утверждение о единственно правильной шахматной классификации. Глубина указана для каждого хода. Короткий локальный поиск может изменить оценку при пересчёте; разные устройства за одинаковое время достигают разной глубины. Не выводим выдуманный Elo игрока, процент точности или метку «гениальный» без обоснованной методики.

Разбор бесплатен, без ограничения количества партий. Есть график за белых, переход к каждому ходу, до трёх легальных вариантов в SAN из позиции перед ходом, ключевые ошибки и итог по сторонам. Остановка сохраняет доступ к уже рассчитанным строкам. Кеш ускоряет повторный расчёт в текущем запуске; готовые строки разбора пока не сохраняются между перезапусками.

## Граница готовности

Это работающая локальная web-версия, пригодная для демонстрации указанных сценариев. Не завершены: 1000+ опубликованных уроков, облачные аккаунты, сетевая игра, мобильные установочные пакеты, физическое тестирование iOS/Android и релизная проверка этапа 14. Квота браузера и очистка данных браузера влияют на локальное хранение. Шахматные варианты вроде Chess960 и сетевые турниры в этот этап не входят.

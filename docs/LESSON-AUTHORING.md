# Как добавить урок

Источник — src/learning/lessons.json. Это JSON-массив: новый урок добавляется как очередной объект. Для изменения интерфейса или шахматных правил это не требует правок. Реальные работающие примеры всех форматов находятся в опубликованных уроках. Схема TypeScript и проверка неизвестных данных расположены вместе в src/learning/schema.ts.

## Метаданные

| Поле                        | Правило                                                                                                                     |
| --------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| schemaVersion               | Сейчас 1                                                                                                                    |
| id                          | Постоянный уникальный ID: латинская буква, затем буквы/цифры/дефисы, до 64 символов; не переименовывать опубликованный урок |
| revision                    | Положительное целое; повысить, если изменены задачи или смысл решений                                                       |
| title / summary / objective | Название до 120, краткое описание и цель до 400 символов                                                                    |
| level                       | Основы, Практика или Мастерство                                                                                             |
| topic                       | Тема до 80 символов                                                                                                         |
| minutes                     | Оценка длительности 1–60 минут, не таймер                                                                                   |
| prerequisites               | До 10 существующих ID без циклов                                                                                            |
| steps                       | 2–64 шага; хотя бы один самостоятельный                                                                                     |
| takeaways                   | 1–5 конкретных практических выводов                                                                                         |

Один урок ограничен 128 КБ. Каталог — до 2000 определений. Эти лимиты валидатора не являются доказательством производительности интерфейса с 2000 уроками; упаковка больших курсов и загрузка контента относятся к этапам наполнения.

## Общие поля шага

id уникален внутри урока. title — до 160 символов. body — 1–5 абзацев, каждый до 1500 символов. fen — проверяемая позиция с королями, корректными правами рокировки и полем en passant. focus — необязательная подсветка до 16 полей, преимущественно для объяснений.

Важно: положение не обязано быть начальной позицией партии, но должно быть законным. Если демонстрируется самостоятельный ход, избегайте уже завершённых позиций, в том числе ничьей из-за недостатка материала. Для объяснения мата или пата завершённая позиция допустима.

## explain

line — необязательная последовательность до 20 UCI-ходов. Каждый ход проверяется; пользователь просматривает её вручную. Вопросов и правильного ответа нет: прочитанный шаг завершается кнопкой продолжения.

## choice

options — 2–6 объектов id, label, feedback. ID уникальны. answer ссылается на ровно один из них. feedback неверного ответа объясняет конкретную ошибку, а не повторяет «неправильно». success объясняет верную идею. hints — 1–3 возрастающие подсказки.

## squares

targets — 1–16 уникальных адресов, например d4, e4, d5, e5. В формулировке явно перечислите критерий выбора: все нужные поля, без исходного поля и т. п. Проверка сравнивает точный набор независимо от порядка. Нужны success и hints.

## move

lines — от 1 до 8 полных решений в UCI. Пример:

```json
{
  "id": "sequence",
  "kind": "move",
  "title": "Размен и развитие",
  "body": ["Возьмите пешку d5. После указанного ответа ферзём развейте коня с нападением на него."],
  "fen": "rnbqkbnr/ppp1pppp/8/3p4/4P3/8/PPPP1PPP/RNBQKBNR w KQkq - 0 2",
  "lines": [["e4d5", "d8d5", "b1c3"]],
  "hints": ["Сначала центральный размен.", "После Qxd5 сыграйте Nc3."],
  "success": "Конь c3 развивается с нападением на ферзя d5."
}
```

Первый ход делает ученик за сторону из FEN; второй — автоматический ответ; третий — снова ученик. Длина нечётная, максимум 15 полуходов. Нельзя задавать несколько разных автоматических ответов после одинакового префикса: это отдельные упражнения. Дубли решений и решения, одно из которых заканчивается внутри другого, отклоняются.

goal необязателен: mate, capture, promotion или castle. Валидатор проверит фактический итог последнего хода. Без goal окончание перечисленной линии считается выполненной конкретной учебной целью. wrong — необязательные адресные объяснения: объекты move и text. Другой законный ход отклоняется с нейтральной формулировкой, не выдающей его за доказанную шахматную ошибку.

Для одноходового mate платформа принимает и другие законные матующие ходы. Для превращения укажите все разрешённые решения с суффиксом q/r/b/n или явно сформулируйте, какую именно фигуру требует задача. Не требуйте единственный ход, когда есть равнозначный ответ, без проверки позиции.

## Проверка и публикация

```sh
pnpm lessons:validate
pnpm lessons:validate ./path/to/another-catalog.json
pnpm test
pnpm build
```

Валидатор входит в build и CI. Дополнительно пройдите новый урок на доске: неправильный ответ, подсказка, правильное решение, восстановление после перезагрузки и узкий экран. Автоматическая легальность не доказывает качество учебной идеи: проверьте полноту ответов, формулировки и объяснение. Не копируйте коммерческие курсы без разрешения.

Тексты первых 12 уроков написаны для Bastion, позиции — учебные конструкции. Правила сверены с [FIDE Laws of Chess](https://handbook.fide.com/chapter/e012023); это источник правил, не заимствованный курс. Поддерживаемые условия и границы системы описаны в STAGE-9.md.

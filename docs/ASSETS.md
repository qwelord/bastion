# Графика и сторонние компоненты

## Собственные материалы
- `public/pieces/*.png`: 12 прозрачных растровых рендеров, 240 × 280 px. Авторские процедурные модели Staunton, созданные для этого проекта.
- Исходная геометрия, камера и свет: `src/graphics/pieces.ts`.
- Воспроизводимый экспорт: `pnpm dev`, затем `/tools/piece-studio.html`. Каждая фигура скачивается отдельным PNG. Основное приложение не загружает Three.js.
- Знак Bastion: собственный простой силуэт крепостной башни; SVG используется только для иконки, не для шахматных фигур.
- Материалы доски: CSS. Это визуальный прототип текстур, художественная доработка предусмотрена этапом 4.
